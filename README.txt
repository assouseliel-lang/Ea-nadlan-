EA Nadlan CMS starter
1. Create GitHub repository and upload all contents (including .pages.yml).
2. Connect GitHub repository in Netlify, build command python3 build.py, publish directory .
3. Sign in to pagescms.org with GitHub and select repository.
4. Edit properties and settings; Netlify automatically deploys commits.
Note: This is a starter integration; test CMS field compatibility and rendering before going live.
